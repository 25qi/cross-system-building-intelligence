# Cross-System Building Intelligence

智慧建築／智慧社區的 **concept prototype**：示範多個獨立子系統的分散訊號，
如何被整合成同一個 Incident，再結合 Building Context 讓 AI 產生可追溯、
可人工審核的決策建議。

**線上展示：** https://25qi.github.io/cross-system-building-intelligence/
**概念設計與原型說明：** [design.html](https://25qi.github.io/cross-system-building-intelligence/design.html)

> 所有 telemetry、threshold、device ID 與 scenario data 皆為 **synthetic data**，
> 不代表任何公司的實際 production architecture。

## What this prototype demonstrates

```
Telemetry → Normalize → Event → Incident → AI tools/query
          → Analysis → Human Review → Action → New Observation
```

Four boundaries that must be preserved:

- **Observation is the source of truth** — AI adds inference without overwriting the original facts
- **Events are generated by deterministic rules** — AI does not participate in event detection
- **AI does not directly control devices** — every control command requires human approval
- **Action results return to the Observation pipeline** — completing an auditable feedback loop

The four scenarios include **two counterexamples** to verify when the system should remain
quiet, which is just as important as knowing when to raise an alert.

## Run locally

```bash
python3 -m http.server 4178
```
